# Purge and Light

## Rules
- **Light disperses** shadows temporarily — they return the next day if the floor is revisited.
- **A photograph traps** lesser shadows permanently. See [[The Camera]].
- **[[Mr. Vacancy]] is immune.** It is only ever photographed because it permits it, and every print of it differs slightly from what the shutter saw.
- Each of the [[Filters]] purges a different shadow variant.

## Teaching order

Torch purge in the [[Teaching Pocket]] (D1, demo) → flashgun prescribed by [[Eve]] and the first *played* purge in [[03 LIVED — The Name]] (D2) → the system under pressure in [[Flash-Survival Room]].

## Purge-pinning

A purged room's geometry stops permuting — a permanent record; see [[Purged Rooms]] and [[Permutation and Persistence]].

## The final purge

Burning the usher on the last night is a gate for [[I See You — The True Ending]]. Unloseable: arriving unprepared throws you back, never kills you. See [[Usher Burned]].
