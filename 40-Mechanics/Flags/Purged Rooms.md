# Purged Rooms

## What the Building remembers

Which rooms have been purged. **A purged room's geometry stops permuting** — the player can pin the map down by clearing it.

## Surfaces where it shows
- The room no longer rearranges between days.
- [[Pip]]'s blueprint, which stops needing correction there — [[Night Phase]].
