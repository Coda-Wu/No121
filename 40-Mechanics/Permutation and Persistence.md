# Permutation and Persistence

The Building rearranges deterministically, from what [[Otto]] did last night.

## Axes (deterministic, always)
- Satchel category carried to bed — hers / institutional / tools / nothing.
- Last door used.
- Alarm-clock state.
- Last conversation (advanced; includes **which twin**, [[Leon]] or [[Noel]] — see [[Tie Continuity]]).

Authored beats override cleanly. The steering epiphany — the first *deliberate* permutation — lands in [[LIVED — The Name]].

- Permanent **"the Building remembers"** flags — one note each in `40-Mechanics/Flags/`.

- **Purge-pinning:** a purged room's geometry stops permuting. See [[Purged Rooms]].
- [[Room 101]] and everything of [[Eve]]'s is untouched by permutation; the darkroom is permutation-anchored.
