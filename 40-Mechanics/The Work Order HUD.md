# The Work Order HUD

The day's work order is the only persistent HUD in the game, and it is diegetic: a physical sheet [[Otto]] carries.

## Behaviour

- **Docked.** It rests against a screen edge as a thin paper tab — the corner of a sheet, nothing more. It never blocks the view.
- **Glide-out.** It slides out smoothly when called, and slides back when released. The motion reads as paper, and it sounds like paper.
- **Called two ways.** Mouse: hovering the screen edge. Controller and Deck: a **hold-to-peek** button. The design is cursorless from day one per [[Commercial Frame]], so the pointer method is the convenience and the button is the real one.
- **Per-scene suppression.** A flag hides it completely where immersion matters: cutscenes, dreams and [[The Ward]], the mind-spaces in [[The Delusions]], the bridge, [[Anna's Flat]], the underwater heart, and the climax of any pocket.

## Contents

It writes itself. Nothing on it is a player action — see [[The Day Loop]].

- The day's 2–3 mundane jobs.
- A line per certification as [[The Ruler]] signs one: MEASURED / SCHEDULED / DISCREPANCY / SIGNED, O.
- **The live count** — IRREGULARITIES LOGGED: n OF m. Canon carried this as a night line; it now runs during the day, so the player always knows how many remain without opening anything.

## The rule it protects

**The blueprint is for planning and never for recording.** If a design ever requires the player to open the map to log a finding, that design is wrong. The work order absorbs all recording, automatically.
