# The Organ Map

> [!warning] Top-secret layer. The Building is [[Anna]] — mind and body. See [[The Ontology]] and [[The Body]].

## The law

- **Lawful weird = the organ working.** Function performed correctly, in a way no building should perform it.
- **Sick weird = the organ failing.** The specific pathology of that organ.

This is the generative rule for the anomaly catalogue. No anomaly is invented from nothing; each one is derived from the organ of the floor it sits on. See [[The Two-Grammar Rule]].
