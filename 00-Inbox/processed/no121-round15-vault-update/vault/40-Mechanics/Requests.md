# Requests

Ratified in Round 15. See [[Round 15 Decision Record]].

There is no desk and no order. A task reaches [[Otto]] from one of three sources, and each is already inside the scene.

| Source | How it arrives |
|---|---|
| **A resident** | Said aloud, in their own place and words. |
| **[[The Pocket Note]]** | His own lead, added when he learns something. |
| **The place** | Something is visibly wrong. |

The player never walks him somewhere in order to be given a task.

## Three kinds of object

| Kind | What it is | Can it be missed? | What it does |
|---|---|---|---|
| **Key objects** | The eight [[Key Items]] | No. The story does not advance without the object. | The work. Enough for an ending. |
| **Side requests** | A further request from a resident | Yes | Each leads to a hidden object or a clause, and brings that resident's help into the last run and the epilogue. |
| **Hidden objects** | [[MISSING Notices Collected]], [[Clauses Known]], [[NIR True Plan Seen]], [[The Three Hums]] | Yes | The standing gates of [[I See You — The True Ending]]. |

The main mission is the work. Only hidden objects and side requests open the true ending fully. No new currency is added: side requests feed gates that already exist. See [[Side Requests Completed]].

Two key objects can still be lost by a choice: **her courage**, on the deceived path of the bridge, and **her breath**, if the usher is not burned. See [[07 DEED — The Family]].

## A request is a small unit

Each request is written to one template, so that it can be moved or cut without rewriting the chapter.

| Field | Content |
|---|---|
| Giver and place | Who asks, and where they are standing |
| Condition | The episode, the self, and any object that must be held |
| The ask | One spoken line |
| Reach | The rooms it spans |
| Yields | A key object, a hidden object or a clause |
| Board | The posts and threads that it adds. See [[The Corkboard Thread]]. |
| At the end | What it changes on the final night |

## Proposed, not yet ratified 🔧

- **Reach is three rooms.** A request resolves within three rooms of where it was asked. If it must go further, a cut carries him.
- **He never reports back.** The giver comes to the place, or the scene ends there.
- **One side request for each resident**, six in all, at about 150 words each.

## A resident is a witness

A resident is never a quest-giver. A resident is a witness who cannot testify until mended. Afflicted, they know nothing. Mended, each gives one thing of [[Anna]]. The gift is never a reward that he asks for. See [[Mr. Vacancy's Plan]] for what the demon makes of that help.
